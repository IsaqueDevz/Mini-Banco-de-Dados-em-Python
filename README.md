<h1>Mini Banco de Dados em Python</h1>

<h2>📌 Sobre</h2>
<p>Projeto desenvolvido para estudo prático de armazenamento de dados e lógica de programação em Python.  
Este sistema simula um mini banco de dados, permitindo que o usuário cadastre, consulte, altere e exclua registros de forma simples via terminal.</p>
